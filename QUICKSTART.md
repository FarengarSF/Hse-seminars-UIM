# Telegram-бот «Главные новости мира»

Бот собирает русскоязычные новости из Google News (раздел «Мир»), BBC и DW.
Отправляет заголовки, короткие описания из RSS и ссылки на публикации.
Работает на Python 3.10+ без установки сторонних библиотек.

## Быстрая проверка

Откройте терминал в папке проекта:

```sh
python3 -m newsbot --demo
```

Демонстрация использует явно вымышленные новости, не обращается к сети и
не требует токена. Проверка настоящих лент без Telegram:

```sh
python3 -m newsbot --once
```

Режим `--once` сохраняет новости в локальную SQLite-базу и выводит подборку.
При недоступности всех источников он завершится с кодом 1; если в базе есть
ещё свежие новости, они будут показаны с сообщением об ошибке обновления в журнале.

## Запуск в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot`, задайте название и уникальное имя бота.
3. Сохраните полученный токен в переменную окружения **на своём компьютере**:

   ```sh
   export TELEGRAM_BOT_TOKEN='вставьте_свой_токен'
   python3 -m newsbot
   ```

4. Откройте созданного бота, отправьте `/start`, затем `/news`.

Токен не нужно добавлять в исходный код или отправлять в этот чат. Для запуска
нужен доступ к Telegram API и сайтам источников. Бот работает, пока запущен
процесс и компьютер подключён к интернету; для круглосуточной работы запустите
его на постоянно работающем сервере. Остановка: `Ctrl+C`.

Поддерживаются личные чаты с ботом. Каждый пользователь получает отдельную
подписку и фильтр. Публикация в каналы и группы в этой версии не реализована.
Один токен и одна база предназначены для одного запущенного экземпляра.
Используется long polling, поэтому входящий порт и публичный домен не нужны.
Бот проверяет наличие webhook и сообщает о конфликте, не меняя его автоматически.
Способ подключения описан в [Telegram Bot API](https://core.telegram.org/bots/api#getupdates).

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Включить рассылку |
| `/news` или `/top` | Получить текущую подборку |
| `/sources` | Посмотреть источники и результат последней проверки |
| `/keywords` | Посмотреть текущий фильтр |
| `/keywords космос, экономика` | Новости, содержащие любое из слов или фраз |
| `/keywords off` | Вернуть все темы |
| `/status` | Подписка, фильтр и давность успешного обновления |
| `/stop` | Отключить рассылку |
| `/help` | Справка |

Фильтр ищет подстроки в заголовке и RSS-описании без учёта регистра. Он не
переводит текст и не распознаёт синонимы. Можно задать до 10 слов или фраз через запятую.

## Настройка

Редактируйте `config.json`, затем перезапустите процесс:

| Поле | По умолчанию | Значение |
| --- | --- | --- |
| `poll_interval_seconds` | `300` | Проверка лент каждые 5 минут |
| `digest_interval_minutes` | `30` | Автоматическая подборка каждые 30 минут |
| `max_age_hours` | `24` | Новости за последние сутки |
| `digest_size` | `5` | До 5 новостей в одной подборке |
| `database` | `data/news.sqlite3` | История, подписки, фильтры и позиция чтения Telegram |
| `sources` | 3 ленты | Название `name` и HTTP(S)-адрес RSS/Atom `url` |

Другой файл настроек: `python3 -m newsbot --config /путь/к/config.json`.
Относительный путь к базе считается от папки файла настроек.
Встроенные ленты русскоязычные; новые источники сохраняют язык оригинала.
Общие ленты BBC и DW могут содержать также региональные новости и другие темы.

## Как выбираются «главные» новости

Оценка равна `0.7 / (1 + позиция / 5) + 0.3 × (1 − возраст / окно)`:
новость выше в RSS и свежее получает больший приоритет. После выбора статьи
приоритет других материалов того же издателя немного снижается для разнообразия.
Позиция в RSS — приблизительный сигнал: некоторые редакции сортируют ленту
только по времени. Это **не статистика просмотров и не полный мировой рейтинг**.

Повторные URL, включая распространённые метки отслеживания, не создают новые записи.
Разные статьи об одном событии и ссылки Google, ведущие на уже известную статью,
могут остаться отдельными новостями. Семантическое объединение сюжетов не используется.
Если дата отсутствует или повреждена, используется время первого получения.

После `/start` автоматическая рассылка учитывает только новости, добавленные
после подписки. Старые заголовки доступны через `/news`. Каждые 30 минут бот
выбирает до пяти лучших новых материалов; остальные материалы этого периода
не переносятся в следующую рассылку. Если подходящих новостей нет, сообщение
не отправляется. `/news` выдаёт текущий топ и начинает новый период рассылки,
чтобы эта подборка сразу не повторилась автоматически. Повторная команда
`/news` может показать те же материалы — это запрос текущего топа.

История сохраняется при перезапуске. Ошибка одной ленты не останавливает остальные;
сетевые ошибки Telegram повторяются, ограничение `retry_after` учитывается.
При блокировке бота пользователем подписка отключается. В редком случае обрыва
соединения после принятия сообщения Telegram или аварии до записи результата
в базу возможна повторная отправка: абсолютной гарантии «ровно один раз» нет.

## Проверки и структура

```sh
python3 -m unittest discover -v
```

- `newsbot/feeds.py` — RSS/Atom, даты, очистка текста и ссылок.
- `newsbot/ranking.py` — отбор и оформление подборки.
- `newsbot/storage.py` — SQLite, история и подписчики.
- `newsbot/telegram.py` — Telegram Bot API.
- `newsbot/service.py` — команды, обновление лент и расписание.
- `newsbot/network.py` — HTTPS с проверкой сертификатов.
- `tests/` — проверки парсинга, фильтров, подписок, ошибок доставки и перезапуска.

База растёт по мере накопления истории; автоматическая очистка в этой версии
не включена. Доступность отдельных источников зависит от сети — посмотреть
состояние можно через `/sources` и журнал в терминале.
